# 2-minute recording checklist

1. Fill in your name, student ID and repository address in `docs/submission.json`. Generate the cover with `python -m scripts.presentation`. Add the video URL and regenerate once the recording is uploaded.
2. Launch the project with `streamlit run app.py`. Set the browser zoom so the input, selected model and side timing log fit together. Open slides 4, 8 and 9 in another window.
3. Rehearse both messages. Warm up the model once, then click **Clear session**. Silence notifications and check the microphone.
4. Record a single take with your own English narration. Type new inputs on screen. Show the offensive mask, timing log and the four-model comparison, then the architecture and measured results.
5. Aim for 1:45–1:55. Stop before 2:00 and check that the exported recording has sound.
6. Upload the video as YouTube Unlisted or a Google Drive file visible to anyone with its link. Open both the video and repository in a private browser window. Check the weights download if using hosted files.
7. Put both real links on slide 1 and in the submission form. Export and inspect the final PDF. Due Sunday, 22 November 2026.
